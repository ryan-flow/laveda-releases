# LAVEDA 投流助手

本仓库仅提供 Windows x64、Mac Intel x64、Mac Apple Silicon arm64 安装包与在线更新清单，不存放产品源码、用户报表、数据库或密钥。

安装包请从 [Releases](https://github.com/ryan-flow/laveda-releases/releases) 选择与你电脑架构对应的一份。软件内可通过「设置 → 软件更新」检查版本。早期未启用更新的版本需先手动安装一次新版。

当前为受邀测试发行：Windows 尚未代码签名，Mac 使用临时签名、未公证。升级前请备份业务数据，不要全局关闭系统安全保护。

同一次发行的三个架构使用同一版本号，更新清单在全部附件校验完成后发布。
